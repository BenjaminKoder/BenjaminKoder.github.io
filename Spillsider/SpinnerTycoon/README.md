# Lykkehjul med localStorage

Lykkehjul der du spinner for penger, laget i JavaScript i 2022. Pengene lagres i nettleseren med `localStorage`, så de er der neste gang du åpner siden.

**Prøv det:** [benjaminkoder.github.io/Spillsider/SpinnerTycoon](https://benjaminkoder.github.io/Spillsider/SpinnerTycoon/Spinner.html)

## Slik virker det

- Trykk **SPIN** for å vinne penger.
- Bruk pengene på **SPEED UP** for å korte ned ventetiden mellom hvert spin.

## Filer

- `Spinner.html`, `Spinner.js`, `Spinner.css` – siden, spillogikken og utseendet
- `Images/` – grafikk

Versjonen med database, innlogging og ledertavle ligger i [Spillsider/SpinnerTob/saannBenjiVil](../SpinnerTob/saannBenjiVil).
