# Pilsulator

Promillekalkulator laget i HTML, CSS og JavaScript i 2022, og oppdatert frem til 2023.

**Prøv den:** [benjaminkoder.github.io/Spillsider/PilsKalkulator](https://benjaminkoder.github.io/Spillsider/PilsKalkulator/index.html)

## Slik virker den

1. Velg kjønn, og still inn vekt og hvor lenge du har drukket med glidebryterne.
2. Fyll inn drikkene: antall, mengde i desiliter og alkoholprosent. Med **+** legger du til flere typer drikke.
3. Trykk **Beregn**.

Kalkulatoren viser hvor mange pils drikken tilsvarer, omtrentlig promille regnet ut med Widmarks formel, og en tabell over hvordan promillen synker over tid, med en forbrenning på 0,15 promille i timen.

Resultatet er et estimat og kan ikke brukes til å vurdere om man kan kjøre.
