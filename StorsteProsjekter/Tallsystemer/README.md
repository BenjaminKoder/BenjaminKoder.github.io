# Tallsystemer

Informasjonsside om tallsystemer, laget i HTML og CSS i 2022.

**Åpne den:** [benjaminkoder.github.io/StorsteProsjekter/Tallsystemer](https://benjaminkoder.github.io/StorsteProsjekter/Tallsystemer/index.html)

## Innhold

- Hva et tallsystem er, med eksempler fra romertall, muisca og aztekerne
- Bits og bytes, og hvordan datamaskinen bruker totallsystemet
- 2-, 10- og 16-tallsystemet, og hvordan man regner mellom dem
- Hvordan bytes blir til tekst og farger

Alt ligger i `index.html`, med bildene i `Bilder/`.
