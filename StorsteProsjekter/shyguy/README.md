# Mario

Hoppespill i nettleseren, laget i HTML, CSS og JavaScript i 2022. Klikk for å hoppe over hindringene. Poengene øker jo lenger du klarer deg.

**Spill det:** [benjaminkoder.github.io/StorsteProsjekter/shyguy](https://benjaminkoder.github.io/StorsteProsjekter/shyguy/index.html)

## Slik virker det

- Hoppet og hindringene er CSS-animasjoner.
- JavaScript sjekker hvert tiende millisekund om figuren treffer en hindring, og regner ut poengene fra tiden du har overlevd.

Spillgrafikken er hentet fra Mario-spillene.

## Filer

- `index.html`, `game.js`, `game.css` – siden, kollisjonssjekken og animasjonene
- `bilder/` – grafikk
