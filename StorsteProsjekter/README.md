# Benjamins prosjekter

De første prosjektene jeg lagde, fra 2021 og 2022, samlet på én side. De står i rekkefølgen jeg lagde dem, fra den første nettsiden til de første spillene, og viser hvordan jeg lærte HTML, CSS og JavaScript.

**Åpne siden:** [benjaminkoder.github.io/StorsteProsjekter/StorsteProsjekter.html](https://benjaminkoder.github.io/StorsteProsjekter/StorsteProsjekter.html)

## Innhold

- **Nettsider:** første nettside, andre nettside, Sagaen om Ravn Raudsverd og Eduford
- **CSS-øvinger:** flexbox, grid (blant annet et sjakkbrett), tabeller, lister og en mobiltilpasset side
- **JavaScript:** første JavaScript-øving (en kalkulator), et skjema for filmer, Tallsystemer, Mario, klikkespill, Yatzy, Monty Hall og lykkehjul
- **Større prosjekter:** Geometry Dash ish og Pilsulator

Sidene med grønn farge er nettsider, de rosa er øvinger og de gule er spill.

## Filer

- `StorsteProsjekter.html` / `StorsteProsjekter.css` / `StorsteProsjekter.js` – oversiktssiden
- Én HTML-fil eller mappe per prosjekt, for eksempel `Tallsystemer/`, `shyguy/` (Mario) og `4B Hendelser/` (JavaScript-øvinger med hendelser)
